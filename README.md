# Rounder Provider Pilot

Create a comprehensive, responsive web application for an innovative Australian contextual matching platform named "ROUNDER HQ" (stylized as ROUNDER HQ).

The design must feature a premium, modern tech aesthetic: a crisp ivory/off-white background (#FDFDFB), stark charcoal grid blocks for containers (#1F2937), structural rounded panels, and a high-visibility neon lime green accent color (#A3E635) for trackers, metrics, and call-to-actions. Use strong, punchy sans-serif typography for all headings.

In the global header, include:

1. The branding: "ROUNDER HQ" on the left.

2. A prominent, persistent selector toggle labeled "Portal View" to seamlessly switch the interface between:

   - "Student View"

   - "Corporate Hub"
